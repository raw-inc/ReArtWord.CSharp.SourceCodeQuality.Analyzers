# 困ったとき

[ドキュメント一覧](../README.md) · [導入する](installation.md) · [検査を設定する](configuration.md)

## 診断が出ない

まず、参照方法と対象範囲を確認してください。

- NuGetの場合は、復元されたパッケージ内の `analyzers/dotnet/cs/` にアナライザーのDLLがあるか確認してください。
- プロジェクト参照の場合は、`OutputItemType="Analyzer"` と `ReferenceOutputAssembly="false"` を指定してください。
- DLL参照の場合は、通常の `Reference` ではなく `Analyzer` 項目を使用してください。
- `.editorconfig` で診断が `none` になっていないか確認してください。`RAW120A` と `RAW120B` は既定で無効です。
- テストコード、生成コード、対象フレームワークによって適用されない規則があります。[ルール一覧](../README.md#利用する)で対象範囲を確認してください。

IDEの表示だけで判断しづらい場合は、コマンドラインでも確認してください。

```powershell
dotnet restore
dotnet build -warnaserror
```

## アナライザーを読み込めない

`CS8032` や `AD0001` などが出る場合は、メッセージ全文と使用している.NET SDK・IDEのバージョンを確認してください。
v1.0.0はRoslyn 4.13.0を参照し、.NET SDK 10.0.402で検証しています。
古いコンパイラーで読み込んでいる場合は、まず検証済みのSDKで再現するか確認してください。

同じアナライザーをパッケージ参照とDLL参照の両方で指定している場合は、一方に揃えてください。
解消しない場合は、[不具合報告](../../SUPPORT.md)に沿って、再現できる最小のプロジェクトと診断内容を共有してください。

## 行数上限などの設定が反映されない

`RAW101MaxClassLineCount` などは、アナライザーに渡した設定ファイルから読み取ります。
[独自設定の例](configuration.md#行数などの上限を変更する)と比較し、次を確認してください。

1. 設定を記述した `.props`／`.csproj` が `AdditionalFiles` に含まれていること。
2. 数値を正の整数で直接記述していること。
3. `.csproj` に、共通設定を上書きする値がないこと。
4. 条件式や `$(...)` による値の展開を前提にしていないこと。

## XMLコメントを書いても未記載と診断される

CoreのXMLコメント検査では、コンパイラーが解析したドキュメントコメントを使用します。
利用先の `.csproj` または共通の `Directory.Build.props` で、`GenerateDocumentationFile` を `true` にしてください。
設定例は[Coreを追加する](installation.md#coreを追加する)に記載しています。

## privateフィールドの命名で警告が出る

`fieldName` を使う場合は `RAW120A`、`_fieldName` を使う場合は `RAW120B` を選択してください。
`RAW120C` は、同じファイルで両方が有効になっていることを示します。片方を `none` にしてください。

`RAW612` は一般のアンダースコア禁止規則です。
privateフィールドの専用規則を有効にすれば、そのフィールドは専用規則で検査されます。
ローカル変数や定数など、専用規則の対象外には引き続き `RAW612` が適用されます。

## MVVM Toolkitの参照を指摘される

`RAWMVVM001` が出る場合は、MVVMアナライザーを追加したプロジェクト自身が `CommunityToolkit.Mvvm` を参照しているか確認してください。
UIライブラリや別プロジェクトを参照しただけでは、必要な型を解決できない場合があります。
MVVMを使わないプロジェクトへアナライザーを一律適用している場合は、参照するプロジェクトを絞ってください。

## Razorの宣言をコードビハインドへ移すよう指摘される

`RAWRAZOR001` は、`.razor` 内のフィールド・プロパティ・メソッドなどを検出します。
処理や状態は対応する `.razor.cs` へ移し、表示式やイベントの接続は `.razor` に残してください。
`@inject` から生成されたプロパティは対象外です。

`RAWRAZOR002` が出る場合は、画面の終了に合わせて取り消される `CancellationToken` を呼出し先へ渡してください。
詳しい対象と例外は[Razorのルール](../rules/razor.md)に記載しています。
