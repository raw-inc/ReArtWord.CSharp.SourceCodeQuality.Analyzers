# ドキュメント

初めて利用する場合は、[導入する](guides/installation.md)、[検査を設定する](guides/configuration.md)の順に確認してください。
診断が出た場合は、IDに対応するルール一覧から検査内容を調べられます。

## 利用する

| やりたいこと | 読むページ |
| --- | --- |
| プロジェクトへアナライザーを追加する | [導入する](guides/installation.md) |
| 重大度、命名方式、行数上限などを指定する | [検査を設定する](guides/configuration.md) |
| 読み込まれない、設定が効かない、意図しない診断が出る | [困ったとき](guides/troubleshooting.md) |
| 設計、命名、コメント、非同期処理の規則を調べる | [Core のルール](rules/core.md) |
| CommunityToolkit.Mvvm を使う ViewModel の規則を調べる | [MVVM のルール](rules/mvvm.md) |
| Razor の処理配置と取消トークンの規則を調べる | [Razor のルール](rules/razor.md) |
| 不具合や改善案を報告する | [問い合わせ・不具合報告](../SUPPORT.md) |

## 開発する

| 作業 | 読むページ |
| --- | --- |
| ソースからビルドしてテストする | [開発環境と検証](development/build.md) |
| 実装場所とプロジェクトの役割を確認する | [ソース構成](development/architecture.md) |
| 規則を追加・修正し、診断位置と境界を検証する | [ルールを開発する](development/rules.md) |
| バージョンを確定し、配布パッケージを作る | [リリースする](development/releases.md) |
| 変更を提案する | [開発への参加](../CONTRIBUTING.md) |
